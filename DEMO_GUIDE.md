# 🎬 VIRAL VIDEO FORM - COMPLETE DEMO GUIDE (Phases 1-6)

## Application Overview
The Viral Video Form is an AI-powered tool that generates production-ready viral video briefs. Users input research/content, and the system uses OpenRouter AI (GPT-6.1-Terra-Pro) to generate structured video scripts with quality validation.

## ✨ ALL 6 PHASES EXPLAINED

### PHASE 1: CONTENT INPUT 📝
**Captures:** Video identity, research, and topic details
**AI Feature:** Extracts 3 compelling viral "hooks" from research
**Output:** Selected hook becomes foundation for next phases

### PHASE 2: STRUCTURE SELECTION 📊
**Selects:** Viral structure template (Problem-Solution, Story, etc.)
**Chooses:** Hook type and opening style
**Output:** Structure template for screenplay generation

### PHASE 3: SCREENPLAY EXECUTION 🎬
**AI Generates:** Complete 5-scene screenplay
**Includes:** Dialogue, action, camera specs, timing, audio
**Output:** Production-ready screenplay with all specs

### PHASE 4: VALIDATION ✅
**Validates:** Against 52 quality checks
**Checks:** Golden rules, quality gates, neuroscience principles
**Output:** Pass/Fail results + suggested fixes

### PHASE 5: OUTPUT GENERATION 📤
**Generates:** Final specs, timelines, equipment lists
**Exports:** PDF screenplay, production schedule
**Output:** Complete production brief

### PHASE 6: NODE EDITOR 🖼️
**Features:** Visual screenplay editor with drag-and-drop
**Allows:** Scene modification and rearrangement
**Output:** DOCX export ready for production team
